# ألف باء — تعلّم العربية

تطبيق تفاعلي مجاني للمبتدئين في تعلّم العربية، يقدّم الحروف والكلمات والعبارات والألعاب والاختبارات القصيرة باللغة العربية والإنجليزية.

## المزايا

- مكتبة كلمات قابلة للبحث والتصفية.
- نطق الكلمات والعبارات باستخدام Web Speech API.
- تعلّم الحروف والأصوات مع أمثلة عملية.
- لعبة مطابقة واختبار قصير.
- واجهة عربية وإنجليزية متجاوبة مع الهاتف.
- حفظ اللغة المفضلة، نوع الصوت، وعدد الكلمات المراجعة وأفضل نتيجة اختبار محليًا في المتصفح.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## الفحص والبناء

```bash
pnpm check
pnpm build
```

المشروع مبني باستخدام React وTypeScript وVite، ويمكن نشره على Vercel أو أي خدمة استضافة للملفات الثابتة.
